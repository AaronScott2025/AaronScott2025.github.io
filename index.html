My Projects

Solo Project: Data driven Youtube assistant🔗

This app helps users create videos by analyzing previous thumbnails and titles. It uses data insights to generate engaging video titles based on keywords and trends. By examining the performance of past videos, it suggests optimized thumbnails and compelling titles to maximize viewer engagement. The App utilizes Python and Flask, as well as the Google developer API, and AI models such as Flan-T5 and DALLE

Group Project: FutureLink🔗

Future link is a desktop application that seeks to connect users with the all-too-unknown future, providing guidance for decisions that many people find to be overwhelming. This was a collaborative project, where I was the Project Manager. The project features an informative chatbot, investment projections, a budgeting tool, and a questionnaire that uses KNN to determine the best state to live in

Solo Project: Image Captioning using BLIP🔗

In this project, I explored image captioning using the BLIP model. I combined my interest in AI and web development to build an app where users can upload images and get generated captions. Using Python, Flask, and the Transformers library, I created a user-friendly interface. This project helped me understand advanced machine learning models and showed how AI can describe visual content in practical ways.

Group Project: TrailQuest🔗

TrailQuest is an all-purpose hiking desktop application designed to connect hikers, share experiences, display nearby locations, and track hiking progress and adventures. I was the Project Manager in the project, and my proudest contribution software-wise, was the implementation of the Location retriever. loads with the location of the user (via IP address), which is processed and used to show the user the nearest 25 Hiking Trails to their location. If a user has a level of security where the IP cannot be resolved, then the default location is Los Angeles, California. The user can then opt to enter a different location in the query boxes to display hiking locations nearby to that location instead.
